# Counterbranch alpha releases

Scanner-only alpha test kits for Counterbranch GitHub workflows.

The initial supported platform is Linux x86-64 GNU on GitHub-hosted Ubuntu runners.
Kits contain the authorization scanner, base/head comparison, reporting, and required notices.

Use the [Counterbranch Action](https://github.com/counterbranch/counterbranch-action)
with its documented, pinned release configuration. Published kits include signature bundles
and are distributed through immutable GitHub releases.

See [Releases](https://github.com/counterbranch/alpha-releases/releases) for available kits,
qualification results and known limitations. A kit release does not by itself establish that
the public Action workflow has passed acceptance; check the qualification status in its release notes.

## Action qualification follow-up

The kit release notes preserve the status at publication. See the [dated Action qualification record](qualification/2026-10-04-scanner-action.md) for subsequent observations and the limits of each tested revision.
